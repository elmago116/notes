## Abstract

Linked Open Data (LOD) refers to a set of standards and technologies that can be used to represent and connect distributed and heterogeneous data. LOD is data that is both Open (can be shared and reused by everyone regardless of the purpose) and formatted and made available through the Linked Data principles. LOD uses Uniform Resource Identifiers to identify and locate individual resources. It also uses the Resource Description Framework and its *triple* model to represent data, information, and knowledge about the resources in *graphs* and to express links between resources from distributed data sources. In the cultural heritage domain, it is used to connect data from galleries, libraries, archives, and museums (GLAMs) to each other and to domain vocabularies and background knowledge to allow for new types of analyses and visualization. In the context of (post) colonial heritage for example, LOD is used to facilitate the investigation of issues around object provenance and restitution.
