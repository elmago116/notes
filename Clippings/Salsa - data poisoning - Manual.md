Short Guide to Starting the Scoping Review Using SALSA 

(Focus: Identifying Terminology for the Search Phase) 

1. Introduction: Why we start with terminology 

In this project, your thesis focuses on how to defend large language models (LLMs) and other generative AI systems against poisoning attacks, using: 

- Ontologies and knowledge graphs, 
    

- Symbolic / neuro-symbolic reasoning, and 
    

- Human or citizen involvement (e.g. human-in-the-loop, citizen science, reputation or trust mechanisms). 
    

Before running a full systematic search, you need to identify and refine the terminology (keywords and synonyms) that will structure the Search phase of the SALSA methodology. 

You will do this by: 

1. Running an initial “seed” search using four concept blocks. 
    

2. Selecting a small set of highly relevant articles from Scopus and Web of Science. 
    

3. Extracting the terms used in titles, keywords and abstracts of those articles. 
    

4. Updating and extending the four concept blocks with any new, useful terms. 
    

5. Step 1 – Apply the four concept blocks (2015–present) 

First, you will run exploratory searches in Scopus and Web of Science using four concept blocks: 

Concept Block A – Target systems: LLMs / foundation / generative AI 

Examples of search terms: 

- "large language model*", "LLM*", "foundation model*" 
    

- "generative AI", "generative model*" 
    

- "pretrained language model*", "pre-trained language model*" 
    

- "neural language model*" 
    

- "transformer-based language model*", "transformer language model*" 
    

- Names of well-known models: "ChatGPT", "GPT-3", "GPT-4", "LLaMA", "PaLM" 
    

Concept Block B – Threats: data/model poisoning, backdoors, prompt injection 

Examples of search terms: 

- "data poison*", "model poison*", "poisoning attack*", "poisoned data", "poisoned model*" 
    

- "backdoor attack*", "backdoor poisoning", "backdoored model*" 
    

- "training-time attack*", "training time attack*" 
    

- "prompt injection", "prompt poisoning", "instruction attack*" 
    

Concept Block C – Symbolic/semantic defenses: ontologies, KGs, reasoning 

Examples of search terms (pay special attention to symbolic reasoning): 

- "ontology", "ontologies" 
    

- "knowledge graph*", "KG" 
    

- "semantic web", "linked data" 
    

- "symbolic AI", "symbolic reason*", "symbolic logic" 
    

- "neuro-symbolic", "neurosymbolic", "neural-symbolic" 
    

- "logical reason*", "rule-based system*" 
    

- "knowledge representation", "commonsense reasoning", "knowledge-based system*" 
    

Concept Block D – Human / citizen involvement and reputation 

Examples of search terms: 

- "human-in-the-loop", "human in the loop", "human oversight", "human supervision" 
    

- "citizen science" 
    

- "crowdsourcing", "crowd-sourcing" 
    

- "reputation system*", "reputation score*", "trust score*" 
    

- "community moderation" 
    

How to use the blocks in the initial search 

1. In Scopus, use an Advanced Search combining the blocks like this: 
    

- (A: LLM / foundation / generative AI terms) AND (B: poisoning / backdoor / prompt injection terms) AND (C or D: ontology / KG / symbolic / human involvement terms). 
    

2. In Web of Science, run a similar “Topic” search combining the same blocks with AND/OR. 
    

3. Apply the same filters in both databases: 
    

- Years: 2015–present 
    

- Language: English 
    

- Document types: include all (articles, conference papers, reviews, book chapters, etc.). 
    

4. Record for your notes (you will need this in the thesis methods section): 
    

- Exact query used (copy–paste it somewhere). 
    

- Date of the search. 
    

- Number of results in Scopus and in Web of Science. 
    

3. Step 2 – Select the 10 most relevant papers in Scopus and in WoS 

From the results of the initial search, you will now choose a small, high-quality sample of articles to study the terminology in more detail. 

Do this separately for Scopus and Web of Science: 

1. Sort the results by “Relevance” (or the database’s closest equivalent). 
    

2. Starting from the top of the list, read the titles and abstracts to judge relevance to your thesis (LLMs or generative models, poisoning, and some connection to ontologies/KGs/symbolic reasoning and/or human involvement). 
    

3. Select the first 10 clearly relevant articles in each database. 
    

- If a paper is obviously off-topic, skip it and move to the next one. 
    

4. Note whether any articles appear in both databases. (This will help you understand duplication across sources later.) 
    

You should now have: 

- 10 relevant Scopus articles 
    

- 10 relevant Web of Science articles (some may be duplicates, which is fine at this stage). 
    

4. Step 3 – Identify terms in titles, keywords, and abstracts 

For these selected articles, your goal is to discover how the research community actually talks about these topics. 

For each of the selected articles: 

1. Extract and write down: 
    

- The exact words and phrases in the title that match any of the four concept blocks. 
    

- All author keywords and, if available, database keywords (e.g. “Keywords Plus” in WoS). 
    

- Important phrases in the abstract related to: 
    

- LLMs / generative models 
    

- Poisoning / attacks 
    

- Ontologies / knowledge graphs / symbolic or neuro-symbolic reasoning 
    

- Human involvement, citizen science, reputation, trust, etc. 
    

2. Organise this in a simple table or spreadsheet, for example: 
    

- Column 1: Article ID or citation 
    

- Column 2: Terms related to Block A 
    

- Column 3: Terms related to Block B 
    

- Column 4: Terms related to Block C 
    

- Column 5: Terms related to Block D 
    

- Column 6: Notes (e.g. “new synonym”, “variant spelling”, “very general term”, etc.) 
    

3. Pay attention especially to: 
    

- Synonyms you had not used before. 
    

- Variant spellings (e.g. neurosymbolic vs neuro-symbolic). 
    

- Broader umbrella terms (e.g. “trustworthy AI”) that might be useful to include. 
    

5. Step 4 – Identify new terms to incorporate into the four concept blocks 

Finally, you will update and refine your four concept blocks using what you found. 

1. For each new term you extracted in Step 3, decide: 
    

- Which block it belongs to (A, B, C, or D). 
    

- Whether it is: 
    

- A clear synonym or closely related term → good candidate to add. 
    

- Too generic (e.g. very broad words like “AI” alone) → probably not add, unless it is needed. 
    

2. Update each concept block with the new terms. 
    

- Keep the original terms. 
    

- Add new synonyms or variants as additional OR-terms inside the block. 
    

3. Rewrite your search queries for Scopus and Web of Science using the updated blocks: 
    

- Still combining them as: (Block A) AND (Block B) AND (Block C and/or Block D). 
    

4. Run the search again with the updated blocks and note: 
    

- New total number of results. 
    

- Whether the top results (titles/abstracts) look more relevant, less relevant, or about the same. 
    

This completes the terminology refinement step for the SALSA Search phase. You will then be ready to enter the more formal Search and Appraisal phases, using your improved concept blocks and queries.
